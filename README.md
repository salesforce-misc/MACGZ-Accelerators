# MACGZ Accelerators

A catalog of accelerator repos. The layout follows the Sales Agreement Agent one-pager: a navy introduction on the left, capability cards on the right.

Open `index.html` in a browser, or serve this folder and visit the site root.

## Add a repo

Add an object to the `window.ACCELERATORS` array in `assets/catalog.js`. Give it a unique `id`. The catalog card and the one-pager both read from that object.

The first entry is [MACGZ-salesagreementagent](https://github.com/salesforce-misc/MACGZ-salesagreementagent).
